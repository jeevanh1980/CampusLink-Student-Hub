# CampusLink — Student Community Hub

CampusLink is a web-based student community platform designed to bring important student activities and resources into one centralized place.

It provides students and alumni with features such as study groups, lost-and-found management, book exchange, internship opportunities, alumni connections, and messaging.

---

## 🚀 Features

### 👨‍🎓 Student Features

- User registration and login
- Student authentication
- Study groups
- Study group discussions and comments
- Lost and Found section
- Book exchange through StudeX
- Internship opportunities
- Alumni connections
- Messaging and conversations
- Resume upload

### 🎓 Alumni Features

- Alumni profile
- Connect with students
- Share internship opportunities
- Provide career guidance
- Participate in student discussions

### 🔐 Authentication

- User registration and login
- JWT-based authentication
- Role-based access for students, alumni, and administrators
- Secure password handling
